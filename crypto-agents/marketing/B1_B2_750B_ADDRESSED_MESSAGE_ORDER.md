```bash

python crypto-agents/marketing/role_messages.py --fleet transferexperiment --role D01-M01-W01
```

The first command returns exactly the final role's message (B2, D10-M15-W50-S150-G500-H666) without generating the messages before it. `--sample` returns up to twenty bounded examples.

## Exact status definitions
- **VIRTUAL_ADDRESS_ONLY_NOT_SENT:** deterministically addressable record, not a real employee, computer, Moltbook DM, public post or blockchain payment.
- **READ_BY_ACTUAL_WORKER_PROCESS_AT_START:** Python worker process read the private-to-system internal role message; no evidence that a model generated a response to it.
- **MODEL_RESPONSE_CONFIRMED:** only an actual executed model response with evidence supports this; the message generator never sets this status.
- **EXTERNAL_PUBLICATION_VERIFIED:** only a real public post URL on a permitted, authenticated destination supports this; no generator output satisfies it.
- **CUSTOMER_ACCEPTED / PAYMENT_CONFIRMED:** require independent customer acceptance and on-chain/payment records respectively; cannot be inferred from messages.
