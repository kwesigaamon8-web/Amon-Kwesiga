## Tasks that real volunteers or activated workers can choose
1. **B1 / promotion:** Check the free toolbox on desktop/mobile and report working/not working with a reproducible screenshot or test result; write a nonduplicate tutorial for one useful tool.
2. **B1 / localization:** Improve accessible explanations in French, Spanish, Kiswahili, Arabic or other languages; verify with a proficient reviewer before publication.
3. **B1 / developer community:** Identify one relevant community that expressly allows showcasing original free tools. Report that community's rules. Only publish after confirming permission and use a legitimate authorized account.
4. **B2 / source QA:** Add deterministic regression tests for one of the 55 tools or investigate one reproducible defect; report steps to reproduce, expected result and actual result.
5. **B2 / accessibility:** Check keyboard navigation, labels, mobile layout, focus states and contrast; produce a targeted patch or test.
6. **B2 / new product:** Build an original browser utility with source, a truthful feature description, tests, license compatibility and a realistic worked example.
7. **Chief D / coordination:** Record real worker task ID, evidence URL, QA result, contributor acceptance, published link and customer enquiries. Do not equate roles with live bots or posts with income.
8. **Chief D / privacy and security:** Reject uploads of private accounting or customer data, arbitrary network calls, cryptocurrency private-key access or scripts violating site terms.
