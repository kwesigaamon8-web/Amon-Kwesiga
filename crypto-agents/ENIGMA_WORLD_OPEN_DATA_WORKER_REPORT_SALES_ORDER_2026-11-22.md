## Approved original data-source discovery starting points
- [World Bank Data Catalog](https://datacatalog.worldbank.org/): development/economic statistics; World Bank's default World Bank-produced open-data license is CC BY 4.0 with additional terms. Check each dataset and provider terms before commercial reuse. [Licensing](https://datacatalog.worldbank.org/public-licenses).
- [Wikidata](https://www.wikidata.org/wiki/Wikidata:Data_access): public structured entities licensed CC0; verify sourced statements independently and avoid compiling private-person dossiers. [Licensing](https://www.wikidata.org/wiki/Wikidata:Licensing).
- [Data.gov Catalog API](https://resources.data.gov/catalog-api/): searchable US public data *metadata*; dataset access and terms vary. Do not assume catalog metadata is the dataset or that every dataset is unrestricted. [User guide](https://data.gov/user-guide/).
- [data.europa.eu](https://data.europa.eu/en): European public-data catalogue; **not all** indexed datasets permit commercial resale (some have non-commercial terms). Verify each dataset license. [FAQ](https://data.europa.eu/en/faq).
- [OpenStreetMap](https://www.openstreetmap.org/copyright): geospatial data under ODbL; comply with attribution, database conditions and provider API usage policy. [Guidelines](https://osmfoundation.org/wiki/Attribution_Guidelines).

Add other legitimate official sources only after checking originality, privacy, terms, throttling and commercial rights. Open access does **not** mean automatically open-licensed. No harvesting account-restricted data, private address/location tracking, breached datasets, blocked APIs, bulk IP scans, paywall bypass, classified data, doxxing or hidden personal-data dossiers. Avoid sensitive security infrastructure locations.
