**Date:** 20 November 2026  
**Owner question:** "Check through the code of the workers and identify why they can't execute the task."

## Main answer

The code configured a very large **virtual** hierarchy but had separate critical defects in the **real model subprocess** path. The recent **ten-model** recurring shift failed on worker startup, although the 900 Python-only workers could pass simpler source-audit tasks. This is not a contradiction: those are different code paths. Fixing the process startup does **not** prove that the AI model will finish, understand the command, earn revenue or make payments.
