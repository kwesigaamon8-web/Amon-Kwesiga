For every failure:

1. Record the precise symptom and reproducible evidence.
2. Identify which component, process, instruction or commercial stage failed.
3. Determine the actual root cause, rather than treating the first symptom as the cause.
4. Develop the smallest effective correction.
5. Apply changes only within existing permissions.
6. Test the correction against the original failure.
