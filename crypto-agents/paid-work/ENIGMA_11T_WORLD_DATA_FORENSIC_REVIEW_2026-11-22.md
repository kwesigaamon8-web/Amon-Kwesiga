## Technical root cause and correction
1. **One virtual address ≠ one executing worker:** `director_grade_work.py` is a prompt/role packet generator, not a process scheduler. The canonical manifest is readable but no per-role live acknowledgment, runtime process ID, output artifact and parent sign-off exists for all 11.25T. Avoid any active-number claim beyond observed logs.
2. **Owned source existed but buyers could not view it on automatic host:** Two new report pages and Markdown samples were missing from the static hosting workflow asset list. Added them to push triggers, ZIP contents, expected file names, independent remote file checks and HTML validity checks. Live success depends on actual Actions run.
3. **Marketing not equal to order:** The owned GitHub sales issues are valid listings but show no external buyer interaction. Creating more unrequested reports is an inferior earnings strategy to finding one real eligible buyer who accepts the payment network and terms.
4. **Data credibility before pricing:** Public access is not blanket license to resell a raw dataset; the new samples use simple original comparisons, named publisher/year and source terms, with no private data. The pilot fails closed on ambiguous source/license metadata.
