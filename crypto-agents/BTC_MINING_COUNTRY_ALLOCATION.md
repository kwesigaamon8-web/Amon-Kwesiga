# Bitcoin mining by country — 30 B systems and internet activity

Country internet activity is estimated from World Bank World Development Indicators, using `SP.POP.TOTL` (population) multiplied by `IT.NET.USER.ZS` (percentage using the internet) for the newest *same calendar year* available between 2024 and 2021.

Each one of the **30 B1/B2 systems** contains **375,188,632,680 logical role positions**. Country weights are applied independently to each of 30 systems, covering exactly **11,255,658,980,400** virtual positions.

These are **virtual role assignments**, **not actual country deployments**. A country gets zero actual deployed miners and zero verified hashrate unless an operator has provided authorized miner hardware, reported verified running Stratum shares and independently confirmed ownership. This GitHub workflow downloads public statistics and creates CSV/JSON; it **never mines cryptocurrency**. GitHub Actions cryptomining is prohibited by [GitHub's product terms](https://docs.github.com/en/site-policy/github-terms/github-terms-for-additional-products-and-features).

Mining work may run only on locally owned or operator-approved CPU/ASIC machines where power cost, software provenance and hosting terms allow it. Report shares separately from confirmed BTC earnings; solo-pool accepted shares are not Bitcoin block rewards. A global internet-usage count does not measure available miners or profitability.
