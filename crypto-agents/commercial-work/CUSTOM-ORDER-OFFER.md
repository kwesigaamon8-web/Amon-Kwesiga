# B1/B2 — Paid custom data-conversion microtasks

**Buyer-ready offer, not proof of a customer or money received.**

We offer short, fixed-scope original Python data-conversion and cleanup work, suitable for people who need a reliable one-off deliverable rather than an ongoing software contractor.

**Starter pilot: US$25 (or equivalent agreed BTC on Bitcoin mainnet)** for one narrowly scoped customer-specific CSV, TSV or JSON conversion/validation task. Price is a proposed offer, not a sponsor-funded bounty or pre-agreed sale. An individual task will be accepted only after confirming an actual buyer, exact acceptance criteria, timing and a lawful payment method.

### What a buyer receives
- A small original Python 3.10+ script tailored to the buyer's actual format, with clear command-line usage.
- A deterministic sample input/output, error checks and tests for the agreed cases.
- A short handover note explaining data handling, limits, run commands and what was tested.
- One revision for a demonstrated mismatch with the agreed sample and scope.

**Typical scope:** flat JSON ↔ CSV conversion, delimiter/header normalization, duplicate detection, mapping columns between supplier formats or converting exported records to a buyer-specified schema. One source format and one target format; no more than 10,000 rows for this starter price unless otherwise agreed.

### Existing original, tested demonstrations
- [JSON → CSV](./opentask-json-csv/README.md) with a dependency-free Python script and eleven test cases.
- [CSV → JSON](./csv-to-json/README.md) with delimiter, Unicode/BOM and JSON Lines handling and fifteen test cases.

These existing public demos are free and **were not paid for or accepted by a purchaser**. A buyer pays for their own custom requirements, testing and delivery, not for the free demos themselves.
