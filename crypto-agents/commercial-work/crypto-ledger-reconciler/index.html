03 · METHOD

Matching rules

  • Exact transaction ID and output/log index are preferred.
  • If each source has exactly one row for a transaction ID, the tool can match by transaction ID alone and labels that weaker method.
  • Duplicate keys, multiple rows without indexes, asset/network differences and amount differences are flagged for human review.
  • BTC amounts use 8 decimal places; Base USDC uses 6. Integer arithmetic prevents floating-point rounding.
  • Network fees are not allocated across outputs. Reconcile fees separately to avoid double-counting.

Do not post journal entries from this report without reviewing source completeness, transaction purpose, valuation at the relevant date, fees and the applicable accounting policy. This tool does not provide tax, audit or IFRS advice.
