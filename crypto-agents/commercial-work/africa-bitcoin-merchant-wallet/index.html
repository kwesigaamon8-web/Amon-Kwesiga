How to use it safely


Create an invoice using an address you personally control. Share its payment link with a willing customer. When the customer provides a TXID, check the output address, amount and confirmation count. Keep the customer's separate order/acceptance evidence. If an address is reused, matching outputs cannot reliably assign a transaction to a particular order.


Only the public TXID is sent to mempool.space during verification. No wallet secrets are collected, there is no login, and no private data are intentionally stored. Address ownership is not established by this demo. A hosted copy needs internet access for explorer lookups.
