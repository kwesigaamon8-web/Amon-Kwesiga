# EMBERGARDEN — The Last Light (original playable work sample)

This branch contains a real **offline, original, MIT-licensed** browser action game created on 17 November 2026. [Playable source](./index.html) is self-contained and needs no network, wallet, or API key. Download the HTML file and open it in a desktop browser. It is NOT a make.fun submitted entry.

**Game rules:** Protect the central seed over five nights. Shadows attack the heart. Move with WASD, aim/fire with your mouse, dash using Space, spend stardust to heal with 1 or burst with 2, and pause with Escape. After the fifth night you win; if the heart loses all health you lose.

**Evidence:** Chromium tests of the same source checked start, movement/fire, pause/resume, victory and defeat screens. Four actual screenshots (each under 256 KiB) are included in the separately delivered ZIP bundle. No test claims that an external contest was entered or paid.
