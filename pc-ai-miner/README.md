# PC AI Miner

**PC AI Miner** is a community-facing research and open-source collaboration initiative exploring Bitcoin mining on personal computers, honest hash-rate benchmarking, pool configuration, electricity costs, and verifiable mining results.

## Participate

Developers and miners can contribute reproducible CPU benchmarks, efficiency measurements, security reviews, documentation, and legitimate collaboration proposals through this repository's issues. No remote machine, network, or miner may be used without its owner's explicit consent. This project does **not** claim guaranteed earnings or that any distributed worker fleet is currently mining.
