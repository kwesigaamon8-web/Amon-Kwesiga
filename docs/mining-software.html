Source audit and publication plan

To publish any executable mining archive, independently review the entire ZIP, dependencies, miner payout destinations, pool settings, proof-of-work correctness, license, hash tests and Windows behavior. Separate public demonstrator code from wallet-private keys, logs and any account secrets. Sign or hash release packages and only distribute tested archives with explicit opt-in to mining.
