# Enigma / B1 B2 — lawful open-source reuse and attribution policy

## What has actually been copied

The new `global-1000-expansion.mjs` and supporting tooling were written from scratch for this project using common mathematical formulas. No third-party application source code has been copied into the 1,000-tool expansion. The first 500 program IDs remain compatible. A public GitHub file is not automatically free of copyright restrictions.

## Rules before reusing public source

1. Inspect the exact repository/tag/file `LICENSE`, copyright notices, patent conditions and third-party dependencies, not only a web snippet or a "free" marketing label.
2. Identify an actual grant to reuse and redistribute (for example, MIT, BSD-2-Clause, BSD-3-Clause, Apache-2.0, ISC, CC0) and observe all terms. Copyleft licenses such as GPL and AGPL are also free/open-source, but their conditions may require source availability, compatible licensing and network-use compliance; do not silently relabel a copyleft work as MIT.
3. Record each import and modifications in a machine-readable notice: upstream name, upstream URL, exact commit/hash, SPDX license, copyright holder, portions reused, changes, and any third-party notices. Preserve all required copyright and license text.
4. Do not copy proprietary, unavailable-license, noncommercial-only or otherwise incompatible code, or circumvent site access controls.
5. Scan candidate code for malicious behavior, accidental secrets, dependencies and license conflicts; run tests before publishing. No cryptocurrency mining is silently run on visitor hardware.
6. Never claim that an application is ours if it was written by an upstream contributor. Publish a fork notice and give correct credit.
7. Do not treat open data as necessarily license-free. Inspect dataset-specific permissions and cite official source, year, geography and indicator; check API terms.
